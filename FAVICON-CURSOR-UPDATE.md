# DustyLyn favicon and Pixie cursor update

- Includes Safari-compatible favicon.ico, 32px PNG, Apple touch icon, and existing SVG with cache-busting links.
- Recreates the owner-supplied Pixie’s Distribution gold ring and sparkle cursor across all HTML pages.
- Cursor is hidden on touch devices and for users with reduced-motion enabled.
- Existing site content, styling, and contact form are retained.
- Upload extracted ZIP contents to root of existing GitHub repo (not the ZIP itself), commit to main, and keep Pages source main/(root).
- Test https://dustylyn.com/favicon.ico?v=2 and force refresh Safari (Option+Command+R); Safari may cache tab icons until tab reopened.
