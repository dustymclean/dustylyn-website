# Contact form setup

The Let's talk button opens /contact/. The form uses https://formsubmit.co/ to deliver submissions to admin@pixies-pantry.com.

**Activation is required:** Once the site is online, submit one test message and check admin@pixies-pantry.com for FormSubmit's activation email. Click its confirmation link, then submit another test and verify it arrives. Check spam/junk if needed. Until activated, delivery is not established.

Do not put sensitive information in form submissions; a third-party service processes the submissions.

To deploy: copy all contents of this directory into the root of your GitHub Pages repository, commit and push the main branch. Do not upload just the ZIP.
